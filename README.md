# carlnseir

I built this portfolio page (index.html) using only HTML and CSS, no JavaScript, since that's what this first assignment asked for.

The page has four sections: a Hero/intro with my name and photo, an About Me section, a Skills section (some technical stuff plus a couple personal ones like table tennis), and a Contact section with a labeled form. I used semantic tags like header, nav, main, section, and footer instead of just wrapping everything in divs.

For styling I linked an external stylesheet (css/style.css) instead of using inline styles, so the HTML and CSS are kept separate.

I also tried to stick to what we've actually covered in class so far, mainly selectors, the box model, colors and units, and typography, instead of using stuff we haven't learned yet. Wanted to make sure I actually understand and can explain everything in my own CSS. Let me know if anything needs fixing.
